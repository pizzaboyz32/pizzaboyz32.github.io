Full Sense vs Global Esports (Upper Final)

Matchid: 666492

Full Sense ก็ยังคงตอกย้ำถึงความแข็งแกร่งด้าน Firepower ของพวกเขา มันคืออาวุธหลักที่ FS ใช้ในการเอาชนะเหนือ Global Esports ไปได้อย่างชัดเจน ในส่วนของ Global Esports การแก้เกมก็มีให้เห็นอยู่ และ Autumn กับ Patman ที่เป็น Win Condition หลัก ก็ทำงานอยู่บ้าง แต่มันไม่ไหวจริงๆ เมื่อโดน Firepower ของ FS ถาโถมใส่รัวๆ

Map 1 ด่าน Split ช่วงครึ่งแรก Full Sense Dominate ไปหลาย Round มากๆ จากพลังการโถม Firepower ที่รุนแรง ความคมของท่าน Primmie แผงฤทธิ์รัวๆ เช่นจังหวะสอย Raze ถือ Ult กลางอากาศแบบคมๆ แถม Round นี้เป็น Round ที่ Global Esports Stack ถูก Site ด้วย อยู่ใน Site กัน 3 คนก็กันไม่อยู่ 

[แทรก วิดีโอ Hilight1.mp4 คำอธิบายประกอบวิดีโอ "Firepower ท่าน Primmie คมๆ"]

หลังจากโดน FS โถมเกมไวใส่หลายครั้ง GE เริ่มปรับตัว มีการ Pause เพื่อแก้แผน แล้วเขาก็แก้มาทันที ด้วยการ พยายามตัดไฟต้นลม เบรกจังหวะแรกของ FS ให้ได้ ชนจังหวะแรกให้อย่างน้อยตัดได้หนึ่ง แล้วมันก็ได้ผลครับ GE เริ่มตีเกมกลับคืนมาจนดึงเข้า 6-6 ได้สำเร้จ จากตอนแรก FS นำ 5-2 

[แทรกวิดีโอ Hilight2.mp4 คำอธิบายประกอบวิดีโอ "Xavi8k พยายามตัดไฟต้นลม วัดสุด แม้ว่าจะเล่นตั้งรับแบบเซฟๆ ได้ก็ตาม"]

สลับมาฝั่งครึ่ง Protocol default อย่างท่านถือ OP ก็เริ่มทำงานทันที Round แรกที่ซื้อได้ ท่านซื้อ OP มาและก็เป็น Win Condition หลักให้กับทีมแบบสวยๆ

[แทรกวิดีโอ Hilight3.mp4 คำอธิบายประกอบวิดีโอ "Primmie OP 2k Collateral สวยๆ"]

แต่ไม่ทันไร GE ก็แก้ได้ทันที เหมือนกับที่ Xffero ทำใส่ Primmie ในด่าน Fracture นั้นคือ ดันสวน Timing หลบเหลี่ยม OP และตัดจังหวะ OP ได้สวยๆ รวมถึงเลี่ยงการปะทะกับ Operator ทำให้ FS ต้องคิดหนักกับการซื้อ Operator ในอนาคต

[แทรกวิดีโอ Hilight4.mp4 คำอธิบายประกอบวิดีโอ "Autumn ดัก Timing Primmie ตัดได้หน้า A Main"]
[แทรกวิดีโอ Hilight5.mp4 คำอธิบายประกอบวิดีโอ "GE เจาะเข้าตรงกลาง หลังจากจับไต๋ได้ว่า FS ชอบเอา OP วางไว้ Main เป็นหลัก"]

พอ FS เริ่มรู้ตัวว่า Operator ไม่ได้ผลอีกต่อไป พวกเขาจึงเปลี่ยน Protocol การเล่น สลับเอา Primmie มาจับ Vandal อีกครั้ง และเน้นเรื่องการหาพื้นที่เป็นหลัก

[แทรกวิดีโอ Hilight6.mp4 คำอธิบายประกอบวิดีโอ "Primmie กลับมา Vandal และสลับ Protocol เน้นหาพื้นที่ อีกฝั่งต้องการ Main, FS ดันสวนกลางทันที"]

แต่ GE ก็ไหวตัวทัน พยายามแก้เกม ทำ Protocol สุดซับซ้อน ส่ง Patmen Fake TP เข้า B พร้อมส่ง Udotan เข้า Site B เพื่อดึงภาระหน้า A ให้ GE เข้าไซต์ง่ายขึ้้น แต่มันก็ไม่พอ เพราะ FS แก้ได้ เดินตามเกมทัน และ จังหวะยิงที่เหนือกว่า และท้ายที่สุดปิดแมพแรกไปได้นั้นเองครับ

[แทรกวิดีโอ Hilight7.mp4 คำอธิบายประกอบวิดีโอ "Protocol GE สุดซับซ้อน แต่ก็เสียหายรัวๆ เหลืออยู่แค่ 2 คนแม้ว่าได้ Site A มาก็ตาม"]

Map 2 ด่าน Breeze ที่ขึ้้นชื่อว่าเป็นด่านเก่งของ Global Esports กลับกลายเป็นว่า พวกเขาโดนฉีกการเล่นเป็นชิ้นๆ จากพลัง Firepower ของ FS เช่นเคย  เกมฝั่งบุกของ FS เรียกว่า กระทืบ Stomp GE จมดินไปเลย เพราะหลายๆ ครั้งๆ ไม่สามารถทำจังหวะกันได้อยู่ โดนตัด โดน Trade รัวๆ มี Round ที่น่าสนใจอยู่น้อยมาก เพราะ Firepower มารอบนี้ GE ดูดรอปขึ้น อาจเพราะด่านนี้ การวัด Firepower มันเห็นชัดขึ้นกว่าด่าน Split ที่พอเล่นกลยุทธ์ซับซ้อนได้เปรียบอยู่บ้าง

[แทรกวิดีโอ Hilight8.mp4 คำอธิบายประกอบวิดีโอ "Xavi8k พลาดจังหวะยิง ทำให้ Full Sense Scale เข้า Site A ได้ง่ายมาก"]

ครึ่งหลังแม้ว่า GE จะบุกเข้าอยู่บ้าง แต่ FS ก็ประคับประคองเกมได้ จนจบ 8-13 FS เอาชนะ GE เข้าสู่รอบชิงได้สำเร็จครับ

เรียกว่าเป็นหนึ่งในเกมที่ สะท้อนถึงความแข็งแกร่งของ FS อย่างชัดเจนเรื่องของ Firepower และตอนนี้พวกเขามี Protocol ที่ชัดเจนมากขึ้น มีการสลับวิธีการเล่นระหว่าง Round ให้เห็นเมื่อเกมกดดันเกินไป ถือว่าเป็นพัฒนาการที่ดีต่อเนื่อง ยิ่งพวกเขาเข้ารอบชิงแล้วเนี่ย โอกาสแชมป์สูงมากๆ เลยละครับ จุดที่จะติ ก็มีเรื่องเดียว ที่มันดูเป็น nitpicking มากกว่า นั้นคือแผนพวกเขายังไม่ได้มีความหลากหลาย และยังเน้นใช้ Firepower เป็นประกันภัยในบางจังหวะอยู่นั้นเอง รอดูว่าในอนาคตจะเริ่มมีการ Innovate แผนใหม่ๆ มากขึ้นรึเปล่า

ส่วน GE ก็ตอกย้ำในเรื่องความแข็งแกร่ง และจุดอ่อนที่ผมเกริ่นไว้ก่อนหน้า กับการที่พวกเขายังไม่มี Firepower ที่เด่นชัด แม้ว่าจะมีแผนที่ครอบคลุม แก้เกมได้ดี จังหวะ mid round สวยๆ เพียบ แต่ในเคสที่ต้องเผชิญหน้ากับทีมที่ Firepower อันดับต้นๆ ของโลก GE ก็ยังก้าวข้ามไม่ได้ มีเพียงแค่ Patmen ที่ยังทำ Win Condition ให้ เสริมด้วย Autumn ที่ Playoff ก็กำลังมาแรง จุดที่พวกเขาต้องปรับปรุง ก็มีเพียงแค่ ทำอย่างไรให้มี Firepower มากกว่านี้ หรือคิดค้นแผนที่มารองรับสถานการณ์ที่ยิงไม่ชนะมากกว่านี้นั้นเองครับ แต่โดยรวม พวกเขาแสดงศักยภาพออกมาได้แข็งแกร่งอยู่นั้นเองครับ
